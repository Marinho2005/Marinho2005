## About Me

I am a Software Developer and Computer Engineering graduate from Brazil. My work combines full-stack web development, embedded systems and IoT. I build complete solutions, from web and mobile interfaces to hardware integrations and cloud-backed APIs, with engineering as the foundation for creating scalable systems.

My focus areas include:

- Full-stack web applications with React, Next.js, Vue.js and Nuxt
- Backend development and REST APIs with Ruby on Rails, Phoenix and NestJS
- OOP design patterns and clean, maintainable architecture
- IoT pipelines, ESP32 integrations and hardware-software interaction
- Linux administration, Docker and cloud-backed services
- Embedded systems with C/C++ and Arduino

I am always exploring new technologies and improving my skills, seeking to create solutions that make a difference.
